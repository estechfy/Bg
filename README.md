# Bg - Support & Feedback Portal

ようこそ！こちらは Android アプリ **「Bg（バックグラウンド無音録画＆画面オフ録音）」** のサポート・不具合報告・機能要望専用リポジトリです。

---

## 📌 ご案内 / Guidance

本リポジトリでは、ユーザーの皆様からのバグ報告・改善リクエスト・ご質問を受け付けております。

- **不具合・バグの報告**: アプリが正常に動作しない、クラッシュする等の問題をご報告ください。
- **機能リクエスト**: 「こんな機能がほしい」「ここを改善してほしい」といったご意見・ご要望をお寄せください。
- **プライバシーポリシー**: [Privacy Policy](https://estechfy.github.io/privacy-policy/)

※ アプリ本体のソースコードは非公開です。本リポジトリは Issue 運用専用となっております。

---

## 📝 Issue の投稿方法

上部の **[Issues](https://github.com/estechfy/Bg/issues)** タブより、「New issue」ボタンを押して投稿してください。  
（Android アプリの設定画面内の「サポート & フィードバック」からもワンタップで端末情報付きの Issue 作成画面を開くことができます）
